# 快递空包批量筛查工具

纯静态 H5 网页，零后端、零服务器、零数据库，全程浏览器本地运行。

## 一键替换收款码（只需 2 步）

打开 `index.html`，找到以下代码区域（约第 **280 行**）：

```javascript
const PAYMENT_CONFIG = {
  /* ---- 微信收款码图片链接（替换为你的微信收款码图片直链） ---- */
  wechatQR: 'https://via.placeholder.com/160?text=微信收款码',
  /* ---- 支付宝收款码图片链接（替换为你的支付宝收款码图片直链） ---- */
  alipayQR: 'https://via.placeholder.com/160?text=支付宝收款码',
};
```

**操作步骤：**

1. 将你的微信收款码图片上传到任意图床（推荐：阿里云OSS、腾讯COS、七牛云、SM.MS、imgtu.com 等），获取图片直链
2. 把 `wechatQR` 后面的链接替换成你的微信收款码直链
3. 把 `alipayQR` 后面的链接替换成你的支付宝收款码直链
4. **保存文件，完成！不需要改动其他任何代码**

> ⚠️ 图片链接必须是直接可访问的图片 URL（以 `.jpg`、`.png`、`.webp` 等结尾），不能是页面链接。

## 使用教程

### 方式一：直接打开

用浏览器（Chrome、Edge、手机浏览器、微信浏览器均可）直接双击打开 `index.html` 即可使用。

### 方式二：部署上线

将 `index.html` 放到任意 Web 服务器（Nginx、Apache、静态托管等）的目录下即可。

推荐免费托管平台：
- **Vercel** - 拖拽上传即可
- **Netlify** - 拖拽上传即可
- **GitHub Pages** - 免费静态托管
- **Cloudflare Pages** - 免费静态托管

### 使用步骤

1. **输入单号**：在文本框中粘贴快递单号（每行一个），或点击"上传TXT文件"/"上传Excel文件"导入
2. **开始查询**：点击"开始批量查询"按钮，系统自动识别快递公司并查询物流
3. **查看结果**：查询完成后，结果按分类统计展示，可使用筛选功能快速查看
4. **导出表格**（付费）：点击"付费导出分类表格"，支付后输入交易单号验证，即可导出 Excel

### 分类说明

| 分类 | 含义 |
|------|------|
| ✅ 正常物流 | 有完整物流轨迹，运输中或已签收 |

| 📭 仅揽收 | 只有揽收记录，无后续物流 |

## 技术说明

- 纯前端开发：HTML + CSS + JavaScript
- 唯一外部依赖：SheetJS（xlsx）从 CDN 加载，用于 Excel 导入导出
- 物流查询：通过快递100公开查询接口（由于跨域限制，自动使用免费 CORS 代理转发）
- 代理方式：内置 4 个免费 CORS 代理服务自动切换，降低单点故障
- 数据存储：所有数据仅存储在浏览器 localStorage 中
- 单号安全：所有数据仅在本地浏览器处理，不上传任何服务器

## 隐私声明

本工具**不上传、不存储、不泄露**任何快递单号或用户数据。所有操作均在用户本地浏览器中完成。

## 常见问题

**Q: 为什么查询比较慢？**  
A: 为防止API限流，系统每次只查5个单号，间隔300ms。上千条单号建议分批查询。

**Q: 导出Excel报错？**  
A: 确保网络能加载 SheetJS 库（`cdnjs.cloudflare.com`），首次加载需联网。

**Q: 付款后怎么验证？**  
A: 支付后在微信/支付宝账单详情中复制"商户单号"粘贴到验证框即可自动解锁。

**Q: 权限丢失了怎么办？**  
A: 联系客服重新发放解锁码，或在浏览器检查 localStorage 中 `delivery_checker_permission` 是否存在。

**Q: 查询返回「查询失败」或「API无响应」？**  
A: 由于快递100 API 存在跨域限制，需要 CORS 代理转发请求。内置了4个免费代理自动切换，若全部不可用，可按以下步骤自行部署代理：
   1. 注册 Cloudflare 账号（免费）
   2. 在 Workers & Pages 中创建一个 Worker
   3. 将以下代码粘贴到 Worker 中并部署：
   ```javascript
   export default { fetch(req) {
     const url = new URL(req.url);
     const target = url.searchParams.get('url');
     if (!target) return new Response('Missing url param', {status:400});
     return fetch(target);
   }}
   ```
   4. 在 `index.html` 的 PROXY_SERVICES 数组顶部添加你的 Worker 地址
